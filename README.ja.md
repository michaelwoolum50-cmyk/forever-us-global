# Forever Us — いつまでも一緒に（日本）

**忘れてはいけない大切なものがあります。**

Forever Us は、思い出だけでなく、あなた自身を残すためのアプリです。あなたの個性、声、価値観、家系、そしてレガシー。大切な人たちのために、あなたらしさのすべてを記録し、守ります。

## 特徴
- **デジタルレガシーボルト** — 写真、音楽、物語、人生の出来事をひとつの安全な保管庫に
- **家系図** — 家族の歴史を作り、写真・生年月日・出来事・メモを添付
- **レガシーの継承者設定** — 誰が何を見られるかをあなたが決められます
- **Endless AIペルソナ** — 家族が実際に会話できる、あなたの生きたデジタルポートレート
- **夢日記** — 夢や想いをレガシーの一部として記録
- **ライフイベント・タイムライン** — 誕生、卒業、結婚、引っ越しなどの節目を記録
- **コミュニケーションプロトコル** — 指定した日や出来事に届く手紙と音声メッセージ
- **ドキュメントビルダー** — アプリ内でWord文書やExcelシートを作成
- **ボルトバックアップ** — 保管庫全体をZIPで書き出し、どの端末でも復元可能
- **ファミリータスク管理** — 家族みんなの家事リストと日課を管理
